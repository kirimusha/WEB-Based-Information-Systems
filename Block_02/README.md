# Block 02 — Back-End Programming with Java

В рамках практической работы Block 02 я разработала веб-приложение на Java с использованием Apache Tomcat и PostgreSQL.

Приложение позволяет получать данные из базы данных через HTTP-запросы и отображать результаты в виде HTML-таблиц в браузере.

## Используемые технологии

* **Java 21** — язык программирования, на котором реализована серверная логика.
* **Apache Tomcat 10** — веб-сервер и контейнер сервлетов.
* **PostgreSQL 16** — система управления базами данных.
* **JDBC (Java Database Connectivity)** — технология подключения Java-приложения к базе данных.
* **HTML** — формат представления результатов в браузере.

## Структура базы данных

В базе данных хранятся сведения о туристических походах и их участниках. Она содержит четыре таблицы:

* `mountains` — информация о горах: название, высота, страна и сложность восхождения.
* `hikers` — информация о туристах: имя, фамилия, опыт, электронная почта и телефон.
* `trips` — информация о походах: дата, продолжительность, организатор и максимальное количество участников.
* `participants` — сведения об участии туристов в походах.

Таблицы связаны внешними ключами. Например, таблица `trips` ссылается на `mountains`, а таблица `participants` связывает походы с туристами.

## Реализованные сервлеты

### 1. MountainsServlet

Файл: `MountainsServlet.java`

Сервлет предназначен для получения и отображения информации о горах.

Он выполняет следующие действия:

1. Получает параметр `country` из HTTP GET-запроса.
2. Устанавливает соединение с PostgreSQL с помощью JDBC.
3. Выполняет SQL-запрос для получения информации о горах.
4. При наличии параметра фильтрует результаты по стране.
5. Формирует HTML-таблицу с названием горы, высотой и страной.
6. Возвращает HTML-страницу клиенту.

Примеры запросов:

* `http://localhost:8080/Block_02/mountains` — отображение всех гор.
* `http://localhost:8080/Block_02/mountains?country=Russia` — отображение гор, расположенных в России.

Для выполнения SQL-запроса используется `PreparedStatement`, а для чтения результатов — `ResultSet`.

### 2. TripsServlet

Файл: `TripsServlet.java`

Сервлет предназначен для получения информации о туристических походах с возможностью фильтрации по продолжительности.

Он выполняет следующие действия:

1. Получает параметр `minDuration` из HTTP GET-запроса.
2. Проверяет корректность числового параметра.
3. Подключается к базе данных PostgreSQL.
4. Выполняет SQL-запрос с объединением таблиц `trips` и `mountains` с помощью `JOIN`.
5. Отбирает походы, продолжительность которых не меньше заданного значения.
6. Формирует HTML-таблицу с датой похода, продолжительностью, организатором и названием горы.
7. Возвращает результат клиенту.

Пример запроса:

`http://localhost:8080/Block_02/trips?minDuration=10`

Он позволяет получить информацию о походах продолжительностью не менее 10 дней.

## Подключение к базе данных

Для взаимодействия с PostgreSQL я использовала JDBC и PostgreSQL JDBC Driver.

Соединение создаётся с помощью `DriverManager.getConnection()`. SQL-запросы с параметрами выполняются через `PreparedStatement`, а полученные данные обрабатываются с помощью `ResultSet`.

Для обработки ошибок подключения и выполнения запросов используется `try-catch`. Для автоматического закрытия ресурсов применяется конструкция `try-with-resources`.

## Развёртывание и запуск

В процессе выполнения работы я:

4. Реализовала два сервлета.
5. Скомпилировала исходный код с помощью `javac`.
6. Разместила скомпилированные классы и JDBC-драйвер в каталоге веб-приложения.
7. Запустила приложение на Apache Tomcat.
8. Проверила работу сервлетов через браузер.
